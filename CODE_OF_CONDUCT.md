# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text — including standards of behavior, enforcement responsibilities, scope, enforcement guidelines, and attribution — lives at the canonical URL above and is incorporated here by reference.

## Reporting

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported to the project maintainer at **doug@dougjohnson.me**. All complaints will be reviewed and investigated promptly and fairly.

The project maintainer is obligated to respect the privacy and security of the reporter of any incident.

## Enforcement guidelines

The Covenant's enforcement guidelines (Correction → Warning → Temporary Ban → Permanent Ban) apply, as published at the canonical URL.

## Attribution

Code of Conduct adapted from the Contributor Covenant, version 2.1, available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
